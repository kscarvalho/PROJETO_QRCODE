# 📱 Gerador de QR Code

Uma aplicação web simples e eficiente para gerar **QR Codes** a partir de textos ou URLs.
Ideal para praticar integração com APIs, manipulação do DOM e criação de interfaces interativas.

---

## 🚀 Funcionalidades

* ✅ Geração de QR Code em tempo real
* ✅ Suporte para URLs e textos personalizados
* ✅ Interface simples e intuitiva
* ✅ Atualização dinâmica do QR Code
* ✅ Design moderno e responsivo

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* API de geração de QR Code

---

## ⚙️ Como funciona

1. O usuário insere um texto ou URL no campo de entrada
2. Ao clicar no botão, o JavaScript captura o valor digitado
3. Uma API externa é utilizada para gerar o QR Code
4. A imagem do QR Code é exibida na tela automaticamente
